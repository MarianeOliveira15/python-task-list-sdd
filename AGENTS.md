# AGENTS.md

## Roteamento

- Use `openspec/` como fonte de trabalho para mudanças com impacto funcional.
- Specs consolidadas vivem em `openspec/specs/`.
- Mudanças em andamento vivem em `openspec/changes/`.
- Antes de implementar uma change OpenSpec, revise proposta, design, specs delta e tasks.
- Para revisão antes de arquivar, use a skill `sdd-review` quando disponível.

## Validação

- Rode os testes proporcionais ao escopo alterado.
- Informe comandos executados e resultado.
- Não marque task como concluída sem evidência.
